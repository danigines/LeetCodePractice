# 83. Remove Duplicates from Sorted List

[![easy](../../src/images/badges/difficulty/easy.svg)](../../src/md/difficulty/easy.md)
[![linked-list](../../src/images/badges/topics/linked-list.svg)](../../src/md/topics/Linked_List.md)

Given the `head` of a sorted linked list, delete all duplicates such that each element appears only once. Return the linked list sorted as well.

### Example 1
> ![A sorted linked list with one duplicated value reduced to one occurrence](https://assets.leetcode.com/uploads/2021/01/04/list1.jpg)
>
> **Input**: head = [1,1,2]
>
> **Output**: [1,2]

### Example 2
> ![A sorted linked list with every duplicated value reduced to one occurrence](https://assets.leetcode.com/uploads/2021/01/04/list2.jpg)
>
> **Input**: head = [1,1,2,3,3]
>
> **Output**: [1,2,3]

## Constraints
- The number of nodes in the list is in the range `[0, 300]`.
- `-100 <= Node.val <= 100`
- The list is guaranteed to be sorted in ascending order.
