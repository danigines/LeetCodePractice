Given two non-negative integers represented as strings, return their product as a string.

Do not use a built-in big-integer library or convert either whole input into an integer.

### Example 1
> **Input**: num1 = "2", num2 = "3"
>
> **Output**: "6"

### Example 2
> **Input**: num1 = "123", num2 = "456"
>
> **Output**: "56088"

## Constraints
- `1 <= num1.length, num2.length <= 200`
- `num1` and `num2` contain only digits.
- Neither string has leading zeroes, except the value `"0"` itself.
