Given two binary strings `a` and `b`, return their sum as a binary string.

### Example 1
> **Input**: a = "11", b = "1"
>
> **Output**: "100"

### Example 2
> **Input**: a = "1010", b = "1011"
>
> **Output**: "10101"

## Constraints
- `1 <= a.count, b.count <= 10⁴`
- `a` and `b` contain only `0` and `1`.
- Neither string contains leading zeroes, except for the string `"0"`.
