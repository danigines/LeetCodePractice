# 66. Plus One

[![easy](../../src/images/badges/difficulty/easy.svg)](../../src/md/difficulty/easy.md)
[![array](../../src/images/badges/topics/array.svg)](../../src/md/topics/Array.md)
[![math](../../src/images/badges/topics/math.svg)](../../src/md/topics/Math.md)

You are given a large integer represented by an array `digits`. Each element is one digit, ordered from most significant to least significant, and the number has no leading zeroes.

Increment the integer by one and return the resulting array of digits.

### Example 1
> **Input**: digits = [1,2,3]
>
> **Output**: [1,2,4]
>
> **Explanation**: The array represents `123`. Adding one produces `124`.

### Example 2
> **Input**: digits = [4,3,2,1]
>
> **Output**: [4,3,2,2]
>
> **Explanation**: The array represents `4321`. Adding one produces `4322`.

### Example 3
> **Input**: digits = [9]
>
> **Output**: [1,0]
>
> **Explanation**: The array represents `9`. Adding one produces `10`.

## Constraints
- `1 <= digits.count <= 100`
- `0 <= digits[index] <= 9`
- `digits` does not contain any leading zeroes.
