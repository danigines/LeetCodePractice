# 82. Remove Duplicates from Sorted List II

[![medium](../../src/images/badges/difficulty/medium.svg)](../../src/md/difficulty/medium.md)
[![linked-list](../../src/images/badges/topics/linked-list.svg)](../../src/md/topics/Linked_List.md)
[![two-pointers](../../src/images/badges/topics/two-pointers.svg)](../../src/md/topics/Two_Pointers.md)

You are given the `head` of a sorted linked list.

Delete all nodes that have duplicate numbers, leaving only distinct numbers from the original list.

Return the linked list sorted as well.

### Example 1
> ![A sorted linked list where every duplicated value is removed](https://assets.leetcode.com/uploads/2021/01/04/linkedlist1.jpg)
>
> **Input**: head = [1,2,3,3,4,4,5]
>
> **Output**: [1,2,5]

### Example 2
> ![A sorted linked list where the duplicated values at the beginning are removed](https://assets.leetcode.com/uploads/2021/01/04/linkedlist2.jpg)
>
> **Input**: head = [1,1,1,2,3]
>
> **Output**: [2,3]

## Constraints
- The number of nodes in the list is in the range `[0, 300]`.
- `-100 <= Node.val <= 100`
- The list is guaranteed to be sorted in ascending order.
